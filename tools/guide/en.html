Vocana

Plain English, any VOICEVOX voice.

Write a script in normal English. Vocana turns every word into katakana the way a Japanese voice can say it, shapes the melody for the mood you asked for, and gives you the voice, captions and word-by-word timing for your video — with every VOICEVOX character, not just one.

1Start in two minutes

1Install VOICEVOXThe free voice engine, from voicevox.hiroshiba.jp. Vocana does not include it. If VOICEVOX is in its usual place, Vocana starts it for you (in the background, with no window).
2Open Vocana.batThe studio opens in its own window. Nothing to install first: Python and everything else Vocana needs are inside the app folder.
3Write, listen, renderPress ▶ next to a line to hear it, then Render. The files land in renders/<script name>/.
First start on Windows. Extract the whole .zip first (right-click → Extract All…) — Vocana cannot run from inside the zip. If Windows asks “Do you want to run this file?” or shows “Windows protected your PC”, choose Run / More info → Run anyway. Vocana removes the “downloaded from the internet” mark from its own folder on the first start, so it asks only once.

Want it in the Start menu? Open Setup.bat instead. It installs Vocana for your Windows user (no administrator rights), adds Start menu and desktop shortcuts, and keeps your files in Documents\Vocana. The folder keeps working too — installing is optional. See Install, update, remove.

macOS or Linux: install Python 3.10 or newer, then run start.sh (or double-click Vocana.command on a Mac). The first start installs numpy and e2k into Vocana’s own folder.

4Writing a script

A script is a plain text file — the studio, Notepad or an AI can write it. One spoken line per line:

gap = 0.4
@cast ME = ずんだもん
@cast METAN = 四国めたん
ME [excited]: Hello! I'm AmirCollider!
METAN [smug]: Hmph. I make cool games too.
ME [cute]: I look harmless... [dark] but I know where your files are. [cute] Hehe ♡
(pause 1.0)
ME [pleading]: Pleeease? I'm *really* good, I promise!
WriteWhat happens
ME [excited]:Speaker tag and mood for the line. Tags are any word (ME, ZUNDA, METAN, ずんだもん); a line without a tag is ME.
[dark] inside a lineThe mood changes from that point on.
*really*Emphasis: that word higher and longer.
Pleeease, soooA letter three times means “stretch”: the word’s long vowel is held.
W-WaitStutter.
! ? ~ ♡Excited rise · question · playful stretched end · sweet end.
... —Trails off (then a pause) · cut off.
Hehe Hmph Uhm ShhSaid the anime way: エヘヘ, フン, アーン, シーッ.
(pause 1.0) on its own lineSilence between lines, in seconds (on top of gap).
One! (pause 0.5) Two!Exactly this much silence between two sentences of one line.
(laughs)Anything else in round brackets is a note to yourself: not spoken.
gap = 0.4Silence between lines for the whole script (default 0.6).
sentence_gap = 0.5Silence between the sentences of every line (otherwise from the punctuation: 0.25 s, 0.32 after ?, 0.5 after ...).
# noteA comment.

Numbers, Mr./Dr., 2.5, 50%, $5, 1st, amircollider.com are read as words. A sentence with kanji in it is Japanese and goes to VOICEVOX’s own reader, so you can mix Japanese lines in. Text VOICEVOX cannot say at all (Persian, Arabic, Korean…) is left out, and the studio tells you where.

5Characters, styles and credits

Every character your VOICEVOX has can read lines — 43 in VOICEVOX 0.25.2, more when you add voice libraries. Say who reads a tag with @cast:

@cast ME = ずんだもん
@cast METAN = 四国めたん / ツンツン, pitch +1, speed 1.05
@cast RYU = aoyama ryusei

The character can be its Japanese name, a romanised name (zundamon, metan, tsumugi…) or a style number. After / comes the base style; then pitch (semitones), speed, volume and intonation. A tag that is itself a character name (METAN:, ZUNDAMON:) needs no @cast. Tags with no cast are read by the default voice — Settings shows which, and the Cast page sets it.

How a mood picks a style

Characters name their styles differently: Zundamon’s sweet voice is あまあま, Yurei-chan’s is 甘々; Takehiro has 喜び where Kotaro has わーい. So a mood asks for a tone, and each character uses its own style of that tone: [happy] is 喜び for 玄野武宏 and わーい for 白上虎太郎, and Zundamon (who has no happy style) keeps ノーマル. When a character has nothing of that tone, the mood’s fallback style is used, and then the character’s base style.

Tones: happy sweet tsun angry sexy whisper hush tired teary defeat scared shy surprised calm strong serious narrator announce.

Credits — please read

Every video that uses a VOICEVOX voice must credit it, in the form the character’s own terms ask for: VOICEVOX:ずんだもん, VOICEVOX:四国めたん, and so on. Vocana writes the exact lines for every character you used into credits.txt in each render, and shows them on the Renders page to copy.

Some characters have further conditions — for example, use by a company, or commercial use, may need permission first. The Cast page marks those characters and shows their terms word for word, as your VOICEVOX provides them, with links to the full rules. Read them before you publish. Vocana adds no conditions of its own to your audio.

6Moods

26 moods come with Vocana. A mood is a tone (which style) and a few numbers (the melody); change them on the Moods page or in moods.json, and add your own.

NumberMeaning
pitchHigher or lower, in semitones.
speed1.0 is normal. Above about 1.12 words blur — energy comes from melody, not speed.
intonationHow much the melody moves (VOICEVOX’s 抑揚).
volumeLoudness. Whisper styles are quiet and need more.
bounceHow much each phrase jumps up or down.
end_rise, exclaim_riseHow far the end of a sentence (and of an exclamation) goes up.
end_stretchHow long the last syllable is held.
pausesLength of the pauses at commas.

7The dictionary

VOICEVOX is a Japanese engine: given English it guesses (“me” becomes the letters “M E”). Vocana writes every word in katakana before VOICEVOX sees it — first from words.json (more than 1,400 common words, plus yours), then from e2k, an English-to-katakana model, for everything else. Nothing is whispered at the end of a sentence, and the words are grouped and accented the way Japanese says loanwords, so they stay clear.

If a word comes out wrong — a name, a game title, a brand — give it the right katakana on the Dictionary page, or in the file:

"amircollider": "アミールコライダー",
"vocana": "ボカナ"

Write it the way it should sound: ー makes a vowel long, ッ is a short stop. The Script page lists the words the model guessed in your script, each with ▶ and Fix.

8What a render gives you

FileWhat it is
full.wavThe whole script in one file.
01_ME.wav, 02_METAN.wav…Every line alone, numbered, named by speaker.
captions.srt / .vttCaptions, one per line.
sentences.srt / .vttCaptions, one per sentence — what a video should follow.
timing.jsonThe start and end of every line, sentence and word in full.wav, in seconds, with the character and style of each line.
timing.txtLine times, easy to read.
credits.txtThe credit lines your video needs.
script.txtThe exact script that made this render.

Any video editor (Premiere, DaVinci Resolve, CapCut, Shotcut…) imports the .wav and the .srt. For word-by-word captions, an editor or an AI tool should read timing.json.

Making the video with AI

On the Renders page, Copy video prompt copies a prompt for Claude Design or any AI video tool. Give it full.wav and timing.json together: the prompt tells it to take every caption’s and every word’s timing from timing.json instead of guessing — with only captions.srt, a tool knows each line’s start and end and guesses the rest, and the video drifts away from the voice.

9Without the studio

Drag and drop: drop one or more script .txt files on render_script.bat. One line: open say.bat, type, hear (renders/say.wav). VOICEVOX is started for you if it is closed.

From a terminal — on Windows with Vocana’s own Python, elsewhere with yours:

app\runtime\python.exe app\launch.py script scripts\Sample.txt
python vocana.py script scripts/Sample.txt
python vocana.py say "Hello! I'm Vocana!" --mood excited --character metan
python vocana.py kana "Hello! I'm Vocana!"
python vocana.py check scripts/Sample.txt
python vocana.py voices
python vocana.py doctor
python vocana.py studio

kana shows the katakana VOICEVOX will get (no engine needed). check reads a script and reports every problem without rendering. doctor checks everything Vocana depends on.

Installing copies your scripts, dictionary, moods and renders from the folder to Documents\Vocana — only those that are not there yet; nothing is ever overwritten. A portable folder in a place it cannot write to (inside Program Files, on a read-only drive) also keeps your files in Documents\Vocana.

Updating

The studio checks once a day whether a new version is out and shows a banner (turn it off in Settings). Installed: extract the new version and open its Setup.bat; the program is replaced, your files stay. Portable: extract the new version and copy your scripts, renders, words.json and moods.json into it.

Moving to another PC: copy the portable folder (or Documents\Vocana) — that is everything.

11If something goes wrong

“VOICEVOX is closed” / “VOICEVOX is not answering”

Open the VOICEVOX app (or press Start VOICEVOX in the studio). If it is open and Vocana still cannot reach it, check Settings → VOICEVOX → Engine address (normally http://127.0.0.1:50021) and press Test. Vocana talks to VOICEVOX directly, never through a proxy or VPN, so those are not the cause.

VOICEVOX does not start by itself

Vocana looks for VOICEVOX in its usual install folder. If yours is elsewhere, set Settings → VOICEVOX location to VOICEVOX.exe, to its engine vv-engine\run.exe, or to the folder. To have Vocana open the whole VOICEVOX app instead of only its engine, choose “The VOICEVOX app”.

Windows says “Windows protected your PC” or asks whether to run the file

Choose More info → Run anyway (or Run). It appears because the files came from the internet; Vocana removes that mark from its own folder on the first start. You can also right-click the downloaded .zip → Properties → tick Unblock before extracting.

“Vocana is still inside the .zip file”

Right-click the .zip → Extract All…, then open Vocana.bat in the extracted folder.

The studio window does not open

Vocana may already be running: look for its window, or open http://127.0.0.1:50210 in a browser. If another program uses that port, Vocana takes the next free one and opens the right address itself. Details of what happened are in logs/vocana.log (and logs/crash.log) in your Vocana files folder.

An antivirus stops Vocana

Vocana is a small Python program: app\runtime\python.exe is the official Python from python.org, signed by the Python Software Foundation. Allow the Vocana folder in your antivirus, or use the installed version.

A word sounds wrong

Look at the line’s katakana on the Script page (or run vocana kana "your sentence"), then give the word the right katakana in the Dictionary. Names and brands almost always need this once.

“… is open in another program” when rendering

A video editor or player has full.wav (or a line file) open from the last render, and Windows does not let anything overwrite it. Close it there, or render under another name.

A line makes no sound

The Script page says why next to the line: often the text is in a writing system VOICEVOX cannot read (Persian, Arabic, Korean…). Write it in English, Japanese or katakana.

“VOICEVOX refused …” in the render notes

VOICEVOX did not accept the katakana of a word. Vocana already read it a simpler way so the render finished; if it sounds odd, give that word a simpler katakana in the Dictionary.

words.json or moods.json “is not valid”

A comma or quote is missing in the file. The message says the line and column. Until it is fixed Vocana uses the shipped version, so nothing stops working. The studio’s Dictionary and Moods pages always write valid files.

The copy from GitHub says it needs its Python runtime

The source code has no app\runtime. Vocana.bat offers to download it (about 34 MB from python.org and pypi.org, every file checked against its SHA-256). Or install Python 3.10+, or get the release from amircollider.com/vocana, which has everything.

Everything else

Settings → Check this computer (or vocana doctor) checks Python, numpy, e2k, your files, free space and VOICEVOX, and says what to do about each.

12Questions

Is Vocana free?

Yes, for personal and commercial work. See the license below.

Can I use the audio commercially?

Vocana adds no conditions. The voices are VOICEVOX characters: follow each one’s terms (shown on the Cast page) and always include the credit line.

Does it need the internet?

No. Vocana and VOICEVOX run on your computer. The only request to the internet is the optional once-a-day update check.

Does it work with AivisSpeech, COEIROINK or other engines?

Vocana is made and tested for VOICEVOX (0.25.2). Engines that copy VOICEVOX’s API may work if you set their address in Settings, but they are not tested.

Can it read Persian?

No — VOICEVOX speaks Japanese, and Vocana makes English (and Japanese) work in it. The studio itself is in Persian, English and Japanese.

Where did VoxTalk go?

Vocana is VoxTalk, grown up. Scripts, words.json and moods.json written for VoxTalk work unchanged and sound the same.

13Privacy

Your scripts, voices and files never leave your computer. The studio only answers on 127.0.0.1, and only to its own page. Once a day (if switched on in Settings) Vocana asks amircollider.com/vocana/version.json whether there is a newer version; that request carries nothing about you or your work.
