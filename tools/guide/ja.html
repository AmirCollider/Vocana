Vocana ボカナ

英語を書くだけで、どの VOICEVOX ボイスでも。

ふつうの英語で台本を書くと、Vocana がすべての単語を日本語の声が言えるカタカナに直し、指定したムードに合わせてメロディーを整え、音声・字幕・単語ごとのタイミングを動画用に書き出します。キャラクターは 1 人だけでなく、VOICEVOX の全員から選べます。

12 分ではじめる

1VOICEVOX をインストール無料の音声合成エンジンです。voicevox.hiroshiba.jp から。Vocana には含まれていません。いつもの場所にインストールされていれば、Vocana が自動で起動します (ウィンドウなしでバックグラウンドに)。
2Vocana.bat を開くスタジオが専用ウィンドウで開きます。事前のインストールは不要。Python など必要なものはすべて app フォルダーに入っています。
3書いて、聞いて、書き出す各行の ▶ で試聴し、書き出し を押します。ファイルは renders/<スクリプト名>/ にできます。
Windows での初回起動。 まず .zip 全体を展開してください (右クリック → すべて展開…)。zip の中からは起動できません。「このファイルを実行しますか？」や「Windows によって PC が保護されました」と表示されたら、実行 または 詳細情報 → 実行 を選びます。Vocana は初回起動時に自分のフォルダーから「インターネットから取得」の印を外すので、聞かれるのは 1 回だけです。

スタートメニューに入れたい場合 は、かわりに Setup.bat を開きます。Windows のユーザーごとに (管理者権限なしで) インストールし、スタートメニューとデスクトップにショートカットを作り、ファイルは Documents\Vocana に保存します。フォルダーのままでも使えるので、インストールは任意です。インストール・更新・削除 を参照。

macOS・Linux: Python 3.10 以降をインストールし、start.sh を実行します (Mac では Vocana.command をダブルクリック)。初回起動時に numpy と e2k を Vocana のフォルダー内にインストールします。

2聞いてみる

これは scripts/Sample.txt を Vocana がずんだもんで書き出したものです。各単語が話されたちょうどその瞬間に光るのは、Vocana が毎回いっしょに書き出す timing.json のおかげです。

3スタジオ

スタジオはあなたの PC の http://127.0.0.1:50210 で動き、アプリのウィンドウとして開きます (タブのない Edge か Chrome。どちらもなければ普段のブラウザー)。書いた内容が PC の外に出ることはありません。

ページ用途
スクリプト話者・ムード・間・強調を色分けするエディター。隣には各行がカードで並び、誰が・どのスタイルで話すか、正確なカタカナ、その行だけを聞く ▶ が表示されます。その下には直すべき問題 (行番号つき) と、モデルが推測した単語の一覧。
キャストどのセリフを誰が読むか。話者タグごとにキャラクター・基本スタイル・音高・話速・音量を選ぶと、Vocana がスクリプトに @cast 行として書き込むので、すべてテキストに残ります。下には VOICEVOX の全キャラクターを立ち絵・サンプル・「英語で聞く」ボタン・クレジット・利用規約とともに表示。
書き出し書き出したものすべて。単語ごとに字幕が進む波形プレイヤー、1 行ずつの音声、全ファイルのダウンロード (.zip でまとめても)、コピー用のクレジット、AI 動画ツール用のプロンプト。
辞書words.json: 単語の読みをカタカナで。検索・追加・編集・試聴。テスト欄で各単語の読みの出所がわかります。
ムードmoods.json: 各ムードのトーンと数値。スライダーと ▶ で、どのキャラクターでも変化を確認できます。
設定言語、テーマ、VOICEVOX の場所と自動起動、更新の確認、ファイルの場所、インストール/アンインストール、PC のチェック、終了。

キーボード

.txt をエディター (または Vocana.bat) にドロップすると開きます。未保存の内容はウィンドウを閉じても下書きとして残ります。スタジオのウィンドウを閉じると数分後に Vocana は自動で終了します。設定 → Vocana を終了 ならすぐに終了します。

4スクリプトの書き方

スクリプトはただのテキストファイルです。スタジオでも、メモ帳でも、AI でも書けます。1 行に 1 つのセリフ:

gap = 0.4
@cast ME = ずんだもん
@cast METAN = 四国めたん
ME [excited]: Hello! I'm AmirCollider!
METAN [smug]: Hmph. I make cool games too.
ME [cute]: I look harmless... [dark] but I know where your files are. [cute] Hehe ♡
(pause 1.0)
ME [pleading]: Pleeease? I'm *really* good, I promise!
書き方効果
ME [excited]:話者タグとその行のムード。タグは自由な単語 (ME、ZUNDA、METAN、ずんだもん)。タグのない行は ME。
行の途中の [dark]そこからムードが変わります。
*really*強調: その単語を高く、長く。
Pleeease、sooo同じ文字 3 回は「伸ばす」: 単語の長母音を保ちます。
W-Waitどもり。
! ? ~ ♡元気な上がり · 疑問 · 遊び心のある伸ばし · 甘い語尾。
... —言いよどむ (そのあと間) · 途切れる。
Hehe Hmph Uhm Shhアニメ風に: エヘヘ、フン、アーン、シーッ。
単独の行の (pause 1.0)行と行の間の無音 (秒)。gap に加算。
One! (pause 0.5) Two!1 行の中の 2 文の間に、ちょうどこの長さの無音。
(laughs)それ以外の丸かっこは自分用のメモ: 読みません。
gap = 0.4スクリプト全体の行間の無音 (既定 0.6)。
sentence_gap = 0.5全行の文と文の間の無音 (指定しなければ句読点から: 0.25 秒、? のあと 0.32、... のあと 0.5)。
# メモコメント。

数字、Mr.・Dr.、2.5、50%、$5、1st、amircollider.com は単語として読みます。漢字を含む文は日本語として VOICEVOX 自身の読み上げに渡すので、日本語の行も混ぜられます。VOICEVOX がまったく読めない文字 (ペルシャ語、アラビア語、韓国語など) は省かれ、スタジオがその場所を示します。

試してみる

下に 1 行書くと、Vocana の読み方どおりに各部分が色分けされ、説明が表示されます。

AI に書いてもらう

スクリプトページの AI プロンプト で、この形式・あなたのムード・キャラクターを ChatGPT や Claude などに教えるプロンプトをコピーできます。作りたい内容を書き足し、返ってきた答えをエディターに貼れば、スタジオが 1 行ずつチェックします。

5キャラクター・スタイル・クレジット

お使いの VOICEVOX にいるキャラクターなら誰でもセリフを読めます (VOICEVOX 0.25.2 で 43 人。音声ライブラリを追加すればさらに)。タグを誰が読むかは @cast で指定します:

@cast ME = ずんだもん
@cast METAN = 四国めたん / ツンツン, pitch +1, speed 1.05
@cast RYU = aoyama ryusei

キャラクターは日本語名、ローマ字名 (zundamon、metan、tsumugi など)、またはスタイル番号で指定できます。/ のあとに基本スタイル、続けて pitch (半音)、speed、volume、intonation。タグ自体がキャラクター名なら (METAN:、ZUNDAMON:) @cast は不要です。キャストのないタグは既定の声で読みます (キャストページで設定)。

ムードがスタイルを選ぶしくみ

スタイル名はキャラクターごとに違います。ずんだもんの甘い声は「あまあま」、ユーレイちゃんは「甘々」。玄野武宏は「喜び」、白上虎太郎は「わーい」。そこでムードは トーン を指定し、各キャラクターはそのトーンに当たる自分のスタイルを使います。[happy] は玄野武宏なら「喜び」、白上虎太郎なら「わーい」、喜びのスタイルがないずんだもんは「ノーマル」のまま。そのトーンのスタイルがないときは、ムードの代替スタイル、次にキャラクターの基本スタイルを使います。

トーン: happy sweet tsun angry sexy whisper hush tired teary sorrow defeat scared shy surprised calm strong serious narrator announce。

クレジット — 必ずお読みください

VOICEVOX の音声を使う動画には、必ずクレジットを記載してください。 書き方は各キャラクターの規約のとおりです: VOICEVOX:ずんだもん、VOICEVOX:四国めたん など。Vocana は使ったキャラクター全員の正確なクレジットを各書き出しの credits.txt に書き、書き出しページにもコピー用に表示します。

キャラクターによっては追加の条件があります (企業での利用や商用利用に事前の確認が必要、など)。キャストページはそのキャラクターに印をつけ、お使いの VOICEVOX が返す規約を一字一句そのまま、全文へのリンクとともに表示します。公開前に必ず読んでください。Vocana があなたの音声に独自の条件をつけることはありません。

6ムード

Vocana には 26 のムードが入っています。ムードはトーン (どのスタイルか) といくつかの数値 (メロディー) からなり、ムードページか moods.json で変更・追加できます。

数値意味
pitch高く・低く (半音)。
speed1.0 が標準。約 1.12 を超えると言葉が不明瞭に。元気さは速さではなくメロディーで出します。
intonationメロディーの動きの大きさ (VOICEVOX の抑揚)。
volume音量。ささやき系は小さいので上げます。
bounceフレーズごとの上下の弾み。
end_rise、exclaim_rise文末 (と感嘆文の文末) をどれだけ上げるか。
end_stretch最後の音節を伸ばす長さ。
pausesカンマでの間の長さ。

7辞書

VOICEVOX は日本語のエンジンなので、英語を渡されると推測で読みます (「me」が「エム イー」になる)。Vocana は VOICEVOX に渡す前にすべての単語をカタカナにします。まず words.json (よく使う 1,400 語以上 + あなたの登録語)、残りは英語→カタカナ変換モデル e2k で。文末の母音が無声化されることもなく、外来語の言い方どおりにまとまりとアクセントをつけるので、はっきり聞こえます。

名前・ゲームタイトル・ブランド名などがうまく読まれないときは、辞書ページかファイルで正しいカタカナを登録します:

"amircollider": "アミールコライダー",
"vocana": "ボカナ"

聞こえてほしいとおりに書きます。ー で母音を伸ばし、ッ で短く詰まります。スクリプトページには、モデルが推測した単語が ▶ と 修正 つきで並びます。

8書き出されるファイル

ファイル内容
full.wavスクリプト全体を 1 ファイルで。
01_ME.wav、02_METAN.wav…1 行ずつ。番号と話者名つき。
captions.srt / .vtt字幕 (1 行ずつ)。
sentences.srt / .vtt字幕 (1 文ずつ)。動画はこれに合わせます。
timing.jsonfull.wav 内のすべての行・文・単語の開始と終了 (秒)。各行のキャラクターとスタイルつき。
timing.txt行ごとの時間 (読みやすい形式)。
credits.txt動画に必要なクレジット。
script.txtこの書き出しに使ったスクリプトそのもの。

どの動画編集ソフト (Premiere、DaVinci Resolve、CapCut、Shotcut など) でも .wav と .srt を読み込めます。単語ごとの字幕には、編集ソフトや AI ツールに timing.json を読ませてください。

AI で動画を作る

書き出しページの 動画用プロンプトをコピー で、Claude Design などの AI 動画ツール向けのプロンプトをコピーできます。full.wav と timing.json をいっしょに渡してください。プロンプトは、字幕と単語のタイミングを推測せず timing.json から取るよう指示します。captions.srt だけだと行の開始と終了しかわからず、残りを推測するので、動画が声からずれていきます。

9スタジオを使わずに

ドラッグ&ドロップ: スクリプトの .txt (複数可) を render_script.bat にドロップ。1 行だけ: say.bat を開いて入力すると聞けます (renders/say.wav)。VOICEVOX が起動していなければ自動で起動します。

ターミナルから — Windows では Vocana 付属の Python で、それ以外ではお使いの Python で:

app\runtime\python.exe app\launch.py script scripts\Sample.txt
python vocana.py script scripts/Sample.txt
python vocana.py say "Hello! I'm Vocana!" --mood excited --character metan
python vocana.py kana "Hello! I'm Vocana!"
python vocana.py check scripts/Sample.txt
python vocana.py voices
python vocana.py doctor
python vocana.py studio

kana は VOICEVOX に渡すカタカナを表示します (エンジン不要)。check は書き出さずにスクリプトの問題をすべて報告します。doctor は Vocana に必要なものをすべてチェックします。

11困ったときは

「VOICEVOX が起動していません」「応答しません」

VOICEVOX アプリを開くか、スタジオの VOICEVOX を起動 を押します。開いているのにつながらないときは 設定 → VOICEVOX → エンジンのアドレス (通常 http://127.0.0.1:50021) を確認し テスト を押します。Vocana は VOICEVOX に直接つなぎ、プロキシや VPN を通さないので、それらが原因になることはありません。

VOICEVOX が自動で起動しない

Vocana は VOICEVOX をいつものインストール先で探します。別の場所にある場合は 設定 → VOICEVOX の場所 に VOICEVOX.exe、エンジンの vv-engine\run.exe、またはそのフォルダーを指定します。エンジンだけでなく VOICEVOX アプリ全体を開きたい場合は「VOICEVOX アプリを起動」を選びます。

「Windows によって PC が保護されました」や実行確認が出る

詳細情報 → 実行 (または 実行) を選びます。インターネットから取得したファイルのため表示されます。Vocana は初回起動時に自分のフォルダーからこの印を外します。展開前に .zip を右クリック → プロパティ → 許可する にチェックしてもかまいません。

「Vocana がまだ .zip の中にあります」

.zip を右クリック → すべて展開… し、展開したフォルダーの Vocana.bat を開きます。

スタジオのウィンドウが開かない

すでに起動しているかもしれません。ウィンドウを探すか、ブラウザーで http://127.0.0.1:50210 を開きます。ほかのプログラムがそのポートを使っていれば、Vocana は次の空きポートを使い、正しいアドレスを自分で開きます。経緯はファイルフォルダーの logs/vocana.log (と logs/crash.log) にあります。

ウイルス対策ソフトに止められる

Vocana は小さな Python プログラムで、app\runtime\python.exe は Python Software Foundation の署名つき公式 Python です。Vocana のフォルダーを許可するか、インストール版をお使いください。

単語の読みがおかしい

スクリプトページでその行のカタカナを確認し (または vocana kana "your sentence" を実行)、辞書に正しいカタカナを登録します。名前やブランド名はたいてい 1 回登録が必要です。

書き出し時に「… is open in another program」

前回の full.wav (や行のファイル) を動画編集ソフトやプレイヤーが開いていて、Windows が上書きを許しません。そちらで閉じるか、別の名前で書き出してください。

音が出ない行がある

スクリプトページのその行の横に理由が出ます。多くは VOICEVOX が読めない文字 (ペルシャ語、アラビア語、韓国語など) です。英語・日本語・カタカナで書いてください。

書き出しのメモに「VOICEVOX refused …」

VOICEVOX がある単語のカタカナを受け付けませんでした。書き出しを止めないよう Vocana は単純な読み方で読み直しています。不自然なら、辞書でその単語をより簡単なカタカナにしてください。

words.json や moods.json が「正しくありません」

ファイルのカンマや引用符が抜けています。メッセージに行と列が出ます。直るまでは同梱版を使うので、動かなくなることはありません。スタジオの辞書・ムードページは常に正しいファイルを書きます。

GitHub 版が「Python ランタイムが必要」と言う

ソースコードには app\runtime がありません。Vocana.bat がダウンロードを提案します (python.org と pypi.org から約 34 MB、各ファイルを SHA-256 で確認)。または Python 3.10 以降をインストールするか、すべて同梱の版を amircollider.com/vocana から入手してください。

そのほか

設定 → この PC をチェック (または vocana doctor) が Python・numpy・e2k・ファイル・空き容量・VOICEVOX を確認し、それぞれの対処法を示します。

12よくある質問

Vocana は無料ですか？

はい。個人でも商用でも無料です。下のライセンスをご覧ください。

音声を商用利用できますか？

Vocana は条件を追加しません。声は VOICEVOX のキャラクターのものなので、各キャラクターの規約 (キャストページに表示) に従い、必ずクレジットを記載してください。

インターネットは必要ですか？

いいえ。Vocana も VOICEVOX もあなたの PC で動きます。インターネットへの通信は、任意の 1 日 1 回の更新確認だけです。

AivisSpeech や COEIROINK などでも使えますか？

Vocana は VOICEVOX (0.25.2) 用に作り、テストしています。VOICEVOX 互換の API を持つエンジンは、設定でアドレスを指定すれば動く可能性がありますが、テストはしていません。

ペルシャ語は読めますか？

いいえ。VOICEVOX は日本語を話し、Vocana はそこで英語 (と日本語) を使えるようにします。スタジオ自体はペルシャ語・英語・日本語に対応しています。

VoxTalk はどうなりましたか？

Vocana は VoxTalk が成長した姿です。VoxTalk 用のスクリプト・words.json・moods.json はそのまま使え、まったく同じ音になります。

13プライバシー

スクリプト・音声・ファイルが PC の外に出ることはありません。スタジオは 127.0.0.1 でのみ、自分のページにだけ応答します。1 日 1 回 (設定でオンの場合)、Vocana は amircollider.com/vocana/version.json に新しいバージョンがあるか問い合わせますが、その通信にはあなたや作品の情報は一切含まれません。
